NO composer exists yet: the session registries live in the operator-UI server process, so the wire carries no rows today and the W151 residual stays recorded — when a later wave composes the accessor, the count composes from the records and the rows ride with no further UI change.

The W151 per-session incident cards are untouched — a card's recorded violation is NOT an incident row (the sourcing pin).

The framing is the strip's own title/hint element, verbatim: "workspace-level live state — never presented as a per-run record" (`WORKSPACE_STRIP_FRAMING`). Degraded names why: nothing answered → "workspace live state unavailable — git unavailable"; one record missing → "git status unavailable" / "worktree list unavailable". Never a fabricated row.
