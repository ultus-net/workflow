- Do not mark tasks complete without fresh verification evidence.
- Capture technical debt as explicit follow-up work instead of silently widening a task.
- Update `ROADMAP.md` when milestone order or scope changes.
- Update `PLAN.md` when a platform architecture decision changes.
- Keep Workflow Guard-specific planning in `apps/workflow-guard-mcp/docs/plan.md` unless it changes the umbrella architecture.
